Three things to know

🤖 Numan has a life

He has 8 needs, like a Tamagotchi. Eat, sleep, gather and build, or he gets grumpy.

🙏 The gods suggest

Viewers send requests like "build a hut." Numan decides whether to do it, later, or not at all.

🧠 A local AI decides

A language model runs on the streamer's own PC. Nothing goes to a cloud service.

How a viewer's idea reaches Numan

One message, five stops. Viewers never control Numan directly.

Who has the final say? Survival beats the brain. The brain beats viewer requests. The brain only picks from a fixed list of actions, and it never runs code.

Run it in three steps

  1. Install Node.js 20.12+.
  2. Double-click start.bat in the project folder.
  3. Open http://127.0.0.1:8787/?ops if it doesn't open by itself.
