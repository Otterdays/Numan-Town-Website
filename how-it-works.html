Under the hood

Five parts, one rule: the sim is the boss.

Only the sim can change the world. The AI can suggest, and the screen only draws what the sim says.

The big picture

💬 Chat (planned)

Twitch messages would become god requests. Not connected yet. Today, requests come from the operator panel or a WebSocket.

↓ requests, over WebSocket

🖥️ The sim (Node.js)

The one true world. It runs the clock, needs, resources, crafting, building, and saving. It validates everything before it changes anything.

↕ the sim asks the brain for a decision, and the brain's answer is checked before use

🧠 The AI brain (Ollama + Ornith 9B)

A local language model. It returns a short JSON answer: a thought, a line of speech, and a goal. The sim checks it before using it.

↕ "what do I remember?" and "remember this"

📚 Memory (embeddings + nightly journal)

embeddinggemma-2 turns notable events into numbers, so they can be searched by meaning. Before each decision it finds the 6 most useful memories for the brain, Ornith-1.5-9B. At night Numan writes a short journal, and the insights from it are saved as memories too.

↓ snapshots, 5 times per second

🎨 The screen (three.js in the browser)

Draws the island, Numan, the day and night, and the HUD. It has no game logic of its own.

↓ captured by OBS

📡 The stream

OBS shows the page at 1920×1080 and sends it to Twitch or YouTube.

Who gets the final say?

  1. Survival comes first. Eating and sleeping are rule-based, so a slow or wrong AI answer cannot starve him.
  2. The AI proposes. It only picks from a short fixed list of actions. It never runs code.
  3. The sim checks. Unknown or broken answers are ignored, and the sim logs a warning.
  4. The screen just shows. It cannot change the world.

If something breaks, the island keeps going. No AI? He follows instincts. Memory server down? He just skips recall. The sim keeps ticking either way.

Locked down by default

The sim listens only on this PC (127.0.0.1). It checks the Host and Origin of every connection, limits how many messages each client can send, and caps how many viewers can connect. Operator commands like reset and speed can be locked behind a token. Viewer text is cleaned before anything uses it.

Words you might hear

LLM

Large language model: the AI behind chatbots. Numan's is small and local.

Ollama

A free program that runs AI models on your own computer.

Quantized

A model squeezed to a smaller size so it fits on a gaming GPU. Some quality is lost.

Embeddings

Turning text into a list of numbers, so similar ideas get similar numbers. That is how memory search works.

JSON

A simple text format like {"type": "build"}. Easy for computers to read.

WebSocket

A two-way connection, so the sim and the screen can talk live.

Node.js

Lets JavaScript run on a computer, not only in a browser.

three.js

A library that draws 3D scenes in a web page.
