Questions

Quick answers.

The short version of the questions people ask most.

Is Numan a real AI?

Partly. A local language model called Ornith 9B picks his next goal and says a short line about every 15 seconds. It runs on the streamer's PC. The sim checks every answer and only uses ones that fit the rules. Without the model, Numan follows simple instinct rules and the island keeps running.

Does it send my data anywhere?

The sim listens only on this PC (127.0.0.1) by default. The brain and memory run locally through Ollama and llama.cpp. Nothing is sent to a cloud AI service by the project itself. Downloads (npm packages, the model file) do need the internet once.

Can a random viewer break it?

Not from the outside. Connections are checked, messages are rate-limited, viewer text is cleaned, and operator commands need a token once you set one. Chat is not connected to the island yet, so there is no open door for viewers today.

Does it need a GPU?

For the brain, yes in practice. The model is about 6.7 GB and we only tested it on a 16 GB AMD card. Smaller setups are untested. Without a GPU or without Ollama, Numan still runs on instincts.

Does it need the internet while streaming?

The sim itself does not need it. You need it for the first setup (downloads) and for sending the stream to Twitch or YouTube through OBS.

Can viewers talk to Numan?

Not yet. Today the streamer sends god requests from the operator panel. A Twitch bridge is planned and needs a word filter and rate limits first. See the roadmap.

Why did he say no?

The brain weighs each request against his needs and mood. If he is hungry or tired, survival comes first. Refusals are part of the show. He answers in character, in a short line.

Does he remember past days?

Yes. Notable moments are stored as memories and searched by meaning when the brain decides. He writes a journal each night. A new era starts with a fresh island, but his memories come with him.

Is it copying a TV show?

No. It is an original world. The idea was inspired by The Truman Show, but none of its characters or places are used.

Can I get the same island again?

Yes. The WORLD_SEED setting in .env sets the layout. The same seed gives the same island.

Where is the code and the docs?

The simulation is in sim/, the screen is in client/, and the design notes are in docs/. This site is in website/. Start with SUMMARY.md for a status overview.

Something is broken. Now what?

Run test.bat quick to see whether the basics still pass. Check the terminal window for error lines. The Run it page lists the settings and tests. Known issues are on the roadmap.
