Get it running

Start Numan's world in about a minute.

Windows is the tested path. You need Node.js. Ollama is optional, and without it Numan just follows his instincts.

Quick start OBS setup

What you need

Required: Node.js

Version 20.12 or newer. Get it from nodejs.org.

Optional: Ollama

Runs the AI brain. Pull the model once, then leave it running.

Optional: a GPU

Helps the AI brain stay fast. Tested on a 16 GB AMD card.

Quick start

Option 1: double-click

  1. Open the project folder and double-click start.bat.
  2. It installs what it needs, starts the sim, and opens the control page.

Option 2: by hand

  1. Open a terminal in the project folder.
  2. Run these three commands: 
    cd sim
npm install
npm start
  3. Open http://127.0.0.1:8787/?ops in your browser.

Just want to read this site?

  1. Double-click start-website.bat in the project folder.
  2. It starts a small local server and opens the site at http://127.0.0.1:8080/website/. It needs Node.js only, no install.

The sim does not need to run for this. Close the "AI Stream Town site" window to stop the site.

Turn on the AI brain (optional)

ollama pull hf.co/ornith-ai/Ornith-1.5-9B-GGUF:Q4_K_M

The HUD shows 🧠 instincts if the AI is off, and 🧠 on when it is running.

Page options

Add to the addressWhat it does
?opsOpens the operator panel: speed (1×, 10×, 60×), say something, and New era (reset).
?obsClean view for OBS. Press H to show or hide the UI.
?freeThe camera does not follow Numan.

If the sim has an operator token set, use ?ops=YOUR_TOKEN to unlock reset and speed.

OBS setup

  1. Add a Browser Source.
  2. Set the URL to http://127.0.0.1:8787/?obs.
  3. Set the size to 1920 × 1080.
  4. Put your webcam, alerts and chat on top as usual.

Settings

Copy .env.example to .env and change what you need. Anything you leave out uses the default.

SettingWhat it controls
TIME_SCALEGame speed. 1 means one in-game day every 24 real minutes.
WORLD_SEEDWhich island you get. Same seed, same island.
MIND_ENABLEDTurns the AI brain on or off.
MEMORY_ENABLEDTurns memory and the journal on or off.
OPS_TOKENPassword for operator commands. Required if the sim is reachable from another PC (16+ characters).

Saving and starting over

The world autosaves every 30 seconds (SAVE_EVERY_SEC). New era (reset) in the operator panel starts a fresh island and carries Numan's memories into it, so he remembers the last era. Journal entries are saved in the world file too, and a readable copy goes to saves/journal.md, which a reset leaves alone.

Want a clean slate? Stop the sim and delete saves/world.json. Memories are stored inside the world file, so they go too. Back the file up first if you want to keep them.

Crash restart: start.bat restarts the sim after an error, after a 3-second pause. This loop is still being tested, so keep an eye on the window during the first streams.

Run the tests

From the project folder, run test.bat. Three modes:

  • test.bat quick: unit, fuzz and end-to-end tests. About 20 seconds.
  • test.bat: the above, plus 20 seeds of 30 game days and live-server abuse tests. About 2 minutes.
  • test.bat long: everything, plus a 5-minute stress run and a 365-day soak. Over 10 minutes.

Run the full version before going live.
