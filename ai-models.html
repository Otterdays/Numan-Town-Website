Why these? Ornith is small enough to run fast on a 16 GB card, and it answers in JSON on request. embeddinggemma-2 is small, so it runs on the CPU's built-in graphics and leaves the big card's memory free for Ornith.

What embeddinggemma-2 is for

Ornith-1.5-9B, Numan's brain, can only read what fits in its prompt. It cannot keep every past moment there. embeddinggemma-2 is the small model that solves this: it turns each memory into a list of 256 numbers, called an embedding. Memories that mean similar things end up with similar numbers, so the sim can search for "the last time I was hungry" even if the words are different.

  1. Save. A notable event, like "I built a hut", is turned into numbers and stored.
  2. Search. Before a decision, the sim turns the current situation into numbers too and finds the closest matches.
  3. Pick. Matches are ranked by how relevant, how recent, and how important they are. The top 6 go into Ornith's prompt.

It does not decide anything and it does not write text. It only finds memories. Ornith-1.5-9B is the model that reads them and decides. The short insights from his nightly journal also become memories, so they can be found later too.

Voice options we are weighing

Roughly ordered by reported size (Piper's size was not in our sources). Sizes and quality come from web sources and are not measured on our PC yet.

Smallest reported

KittenTTS

CPU only, Apache 2.0. Nano is about 15M parameters (roughly 25–56 MB). Micro is about 40M (about 41 MB). Mini is about 80M (about 80 MB).

English only. Developer preview (v0.8). Sizes differ between sources, so check the files.

Proven

Piper

CPU only, runs on a Raspberry Pi 4. The most voices (904). GPL-3.0-or-later license.

Quality estimate is lower than Kokoro's (MOS 3.8–4.0, informal test).

Best sound

Kokoro

82M parameters, Apache-2.0. Sounds better (MOS 4.3–4.5, informal test). Heavier than the other two.

Can use Apple MLX on Macs. Not relevant here.

Current lean: try KittenTTS micro first, with Piper as the fallback. Before picking, measure the real-time speed of each on this CPU. Nothing is decided yet.

Not verified

MOSS-TTS-Nano-100M (about 100M parameters, file size unknown) and Pocket TTS from Kyutai (about 100M parameters, voice cloning). Both were only seen in directory listings.

Models we are not using

The docs also name a larger 35B model (Ornith-1.5-35B-A3B). It might be smarter but slower, so it only gets tried if the 9B is not good enough. The file NVFP4 (NVIDIA-only) cannot run on this AMD card, so it is out.
